# Uko Group 2 OS Yubatswe

Iyi nyandiko isobanura umushinga mu magambo yoroshye. Yifashishe iyo usobanura Group 2 OS.

Group 2 OS ni sisitemu yacu. Yubatswe kuri Linux. Ntitwatahye Linux. Twagumye ibice bituma mudasobwa ikora, hanyuma twashyizeho izina ryacu, amashusho, login, desktop, na installer.

Disiki irangiye ni:

`build\out\GROUP2-OS.iso`

## Igitekerezo mu buryo bworoshye

1. Gutangiza mudasobwa  
2. Menu ya boot (Group 2 OS)  
3. Sisitemu iratangira  
4. Login igaragara  
5. Andika ijambo ry'ibanga  
6. Desktop ifunguka — ububiko n'idock  
7. Niba wahisemo Install, Group 2 OS yimurirwa kuri laptop  

## Icyo twagumye n'icyo twahinduye

Twagumye: kernel ya Linux, Wi-Fi, USB, ijwi, Firefox, installer nyayo.

Twahinduye: izina Group 2 OS, amashusho ya login/desktop/boot, ububiko bw'abanyamuryango (harimo Niyonkuru Tajidini), dock, Terminal, About.

Ntiduvuga ko twanditse kernel nshya. Group 2 OS ni indangagaciro yacu kuri Linux.
